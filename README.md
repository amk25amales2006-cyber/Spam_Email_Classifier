# Spam Email Classifier

## Description
This project is a Machine Learning application that classifies email or SMS messages as Spam or Ham using the Naive Bayes algorithm and TF-IDF Vectorizer.

## Features
- Spam Detection
- Ham Detection
- 96.23% Accuracy
- GUI using Tkinter
- Model saved using Pickle

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Tkinter
- Pickle

## How to Run

Install libraries:

pip install pandas scikit-learn

Run:

python gui.py
